# v0.2.1 — Architecture Consolidation

**2025-08-04** | Tag: `v0.2.1`

---

## What's New

### Architecture: `folders.ts` Split

Refactored the monolithic `src/folders.ts` into three focused modules:

| Module | Responsibility |
| --- | --- |
| `src/foldersStore.ts` | Pure data layer — `foldersState`, storage I/O, CRUD, session metadata, pub/sub change notifications |
| `src/arenaLibrary.ts` | Arena left sidebar injection — 🗂 Session Library entry, inline collapsible section, cross-tab storage sync |
| `src/historyContextMenu.ts` | Right-click menu — Rename / Move to folder, portal DOM, MutationObserver re-binding |

`src/folders.ts` is now a thin facade re-export layer (~34 lines).

### CI

Added GitHub Actions workflow (`.github/workflows/ci.yml`) running on every push and PR:

- `npm ci` — reproducible dependency install
- `tsc --noEmit` — TypeScript type checking
- `npm run build` — Vite production build
- `npm test` — mirror suites (20 assertions) + real-source suites (24 assertions)

### Session Title Unification (v0.2.0)

Consolidated three title sources into a single resolution path with priority:

```
customTitle  (user rename)  →  title  (Arena round)  →  sessionId prefix
```

Single write path (`setSessionCustomTitle`) and single read function (`resolveSessionTitle`). Legacy `historyTitle_*` keys migrated on first bootstrap.

### Testing

- Mirror tests (jsdom): 20 assertions covering extraction, round grouping, conversation store
- Real-source tests (tsx): 24 assertions covering `computeRounds`, `conversationStore`, `resolveSessionTitle`
- Total: **44 assertions**, all passing

### Performance

- Removed temporary performance instrumentation (`__refreshCount`, `__dt`, `console.log [Perf]`)
- Confirmed virtualized-skip check in `startPreScroll` (`scrollHeight <= clientHeight * 2`)

---

## Breaking Changes

None. All existing functionality preserved; only internal module boundaries changed.

---

## Migration Notes

- Callers of `initFolders`, `setupHistoryContextMenu`, `ensureArenaFolderEntry`, etc. do **not** need import changes — `src/folders.ts` re-exports all public APIs as a compatibility layer.
- New code should import directly from the split modules (`foldersStore`, `arenaLibrary`, `historyContextMenu`).
