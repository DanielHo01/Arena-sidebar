# v0.2.1 — Architecture Refinement

Date: 2025
Branch: `main`

## What's New

### CI/CD

- **GitHub Actions workflow** (`.github/workflows/ci.yml`)
  - Triggers on push to `main` / `feat/**` / `refactor/**` and all PRs to `main`
  - Four steps: `npm ci` → `tsc --noEmit` → `npm run build` → `npm test`
  - Concurrency group prevents duplicate runs on the same branch
  - `fail-fast: false` lets all matrix jobs complete even if one fails (full diagnostics)
  - All action versions pinned to full SHA

### Architecture (merged from `refactor/folders-split`)

- **Folders module split into three layers** — each with a single, focused responsibility:
  - `foldersStore.ts` — pure data layer (state, storage I/O, CRUD, pub/sub change notification)
  - `arenaLibrary.ts` — Arena left sidebar injection (🗂 entry, inline Session Library section)
  - `historyContextMenu.ts` — right-click rename + move-to-folder menu
  - `folders.ts` — thin facade re-export (backward-compatible, 34 lines)
- **`setupFoldersStorageSync`** now lives in `foldersStore` with a proper pub/sub pattern
- All call sites (`content.ts`, `conversationStore.ts`, `historyTitles.ts`) updated to import from the correct layer

## Test Coverage

- `npm test` runs 50 assertions across 5 suites (mirror + real source imports)
- Build size: ~53 KB content script / ~16 KB gzip

## Migration Notes

- No breaking API changes — `folders.ts` facade preserves all existing exports
